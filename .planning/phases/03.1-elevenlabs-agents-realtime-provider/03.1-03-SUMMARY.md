### Task 1: Factory Registration

deferred-import pattern exactly. Registration is equal-rank after `nova_sonic`.

### Task 2a: QUAL-03 Integration Test

`tests/integration/test_realtime_elevenlabs.py` mirrors the Gemini Live skip-safe pattern exactly:
- `pytest.importorskip("websockets")` as first statement after imports
- `@pytest.mark.skipif(not ELEVENLABS_API_KEY or not ELEVENLABS_AGENT_ID, ...)` guard
- Connects via async context manager, waits for `SESSION_READY`, sends 3200-byte silence
- NO `commit_client_turn()` — server-side VAD only
- NO secrets emitted to stdout/logs — T-03.1-03-02 mitigated
- `ELEVENLABS_BASE_URL` env var support for EU endpoint override

### Task 2b: README GDPR Setup Guide

Added "Realtime Providers" section to the English part of README.md with:
1. Enterprise plan (EU data residency is Enterprise-only)
2. Zero Retention Mode (TTS, STT, Conversational AI — voice cloning excluded)
3. EU-hosted Custom LLM backend (Azure OpenAI EU or self-hosted)
4. EU data-residency endpoint (`wss://api.eu.residency.elevenlabs.io`)
- Voice Cloning Caveat: not eligible for Zero Retention Mode
- Note on separate EU API key (prevents 403 Forbidden confusion — T-03.1-03-03 mitigated)
- Positions ElevenLabs as recommended GDPR provider; OpenAI/Gemini remain supported
