### Protocol Corrections Applied (from RESEARCH.md)

1. `tool_result_submission_mode="elevenlabs_native"` (not "conversation_item")
2. `agent_response` → RESPONSE_DONE (primary); `agent_response_complete` handled as forward-compatible secondary
3. `append_client_audio` sends `{"user_audio_chunk": "<base64>"}` with NO "type" field
4. `submit_tool_result` sends `{"type": "client_tool_result", "tool_call_id": ..., "result": ..., "is_error": false}`

### Security (T-03.1-01, T-03.1-02)

- `xi-api-key` never appears in the WebSocket URL or logs
- `_connection_error_endpoint()` returns only base_url + agent_id
- fail-fast `ValueError` on empty `api_key`/`agent_id` before any network I/O
