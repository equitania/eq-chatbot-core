## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | _connection_error_endpoint() | mitigate | Return only `wss://api.openai.com/v1/realtime?model=...` — model is safe, api_key must not appear; assert in acceptance criteria |
| T-02-02 | Information Disclosure | self._headers in logs | mitigate | Never call `_logger.debug(self._headers)` or pass headers dict to any log or error message; _headers stays in base class only |
