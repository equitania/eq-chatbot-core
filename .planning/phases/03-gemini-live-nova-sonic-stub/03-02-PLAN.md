<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| library → Gemini Developer API wss:// | api_key travels as ?key= URL query parameter; must never appear in logs or error messages |
| library → Vertex AI wss:// | OAuth bearer token travels in Authorization header; must never appear in logs or error messages; project ID in x-goog-user-project header (project ID is not secret but bearer token is) |
| error path → caller / logs | _connection_error_endpoint() and _redact_sensitive_text() are the gatekeepers — both must strip credentials from any string that leaves the library |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | Developer API `key=` URL param in logs/errors | mitigate | `_redact_sensitive_url` strips `?key=` using parse_qsl/urlunsplit (PROV-07); `_connection_error_endpoint` always calls this; SC-2 unit test in Plan 05 confirms `key=` absent from redacted output |
| T-03-02 | Information Disclosure | Vertex bearer token in exception messages | mitigate | `_redact_sensitive_text` replaces raw `self._secret` (access_token) with `[REDACTED]` via re.sub; ADAPTATION I; SC-2 unit test in Plan 05 confirms bearer token absent from error text |
